앱 열기

1홈 화면에 추가 (권장)

  • 아이폰 — Safari로 접속 → 하단 공유 버튼 → 홈 화면에 추가
  • 안드로이드 — Chrome으로 접속 → 우상단 ⋮ → 홈 화면에 추가
홈 화면에 추가해야 아침 수업 알림을 받을 수 있어요

2시작하기

처음 열면 학교와 학년을 선택합니다. 분반이 있는 학년(전북대 의예2 해부실습 화/수/금, 원광대 의예2 실습 1·2분반)은 이어서 본인 분반을 고르면 내 분반 수업만 시간표에 표시돼요.

학교·학년·분반 변경은 우측 상단 학년 버튼에서 언제든 가능합니다.

3시간표

‹ › 버튼으로 주차를 이동해요. 접속하면 자동으로 이번 주(주말엔 다음 주)가 열립니다.

날짜를 누르면 그날의 할 일 목록이 열려요. 상단 오늘 할 일 버튼으로도 바로 열 수 있어요.

시험은 빨간 테두리로 표시됩니다. 시간표가 변경되면 자동으로 실시간 반영돼요.

4공부 탭

타이머 — 과목을 고르고 공부 시작. 기록은 자동 저장되고 일일 목표 달성률이 링으로 보여요.

시험 D-day — 남은 시험이 가까운 순서로 정리돼요.

백업 — 내 코드가 자동 발급돼요. 폰을 바꾸면 새 폰에서 이 코드를 입력해 기록을 복원하세요.

5필터 탭

수업 시수 — 과목을 누르면 교수님별 수업 시수와 비율이 보여요. 시험 배점이 시수에 비례하니 공부 배분에 참고하세요.

수업 일정 — 원하는 과목만 골라 일정을 모아볼 수 있어요.

6아침 수업 알림

우측 상단 종 버튼을 누르고 알림을 허용하면, 매일 아침 7시 반쯤 오늘 수업 요약과 시험 여부를 알려드려요.

아이폰은 iOS 16.4 이상 + 홈 화면에 추가된 앱에서만 가능해요
